FAQ

Does LocalCut upload anything?

No. It makes no network requests while you edit and has no telemetry.

Do I need to install it?

No. Unzip the release and run localcut.exe.

What does it need?

Windows 10 or 11, 64-bit, and a DirectX 11 GPU. 8 GB RAM is recommended.
