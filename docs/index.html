Architecture overview

LocalCut is one native executable. A GPU compositor draws the preview, a frame cache in RAM keeps scrubbing instant, and bundled FFmpeg libraries handle decode and encode. Projects are single .lcut files that reference your media in place.

Nothing in this pipeline touches the network.
