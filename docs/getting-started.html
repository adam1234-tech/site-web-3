Getting started

Install AdamApp and export your first video in about five minutes.

Install

  1. Download AdamApp-0.2.12-x64.exe from the download page.
  2. Verify the checksum.
  3. Put the file in any folder and run it. There is no installer.
Settings are stored next to the .exe, so moving the folder moves your configuration too.

Create a project

Choose File → New project or press Ctrl+N. Drag media into the bin, or use Ctrl+I to import. Supported files: MP4, MOV, MKV, WAV and PNG.

Make your first cut

  1. Drag a clip from the bin onto the video track.
  2. Click the ruler to place the playhead.
  3. Press S to split the clip, select the unwanted part, and press Delete.

Export

Press Ctrl+E, choose a codec and destination, then start the export. Hardware encoding is used automatically when your GPU supports it.

You can also export from the command line:

adamapp export project.adam --codec h264 --out result.mp4
