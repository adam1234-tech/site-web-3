Getting started

Install LocalCut and export your first video.

Install

  1. Download LocalCut-0.2.12-win64.zip from the download page and verify its hash.
  2. Extract it to a folder you own.
  3. Run localcut.exe.
Nothing is written outside the extracted folder and %APPDATA%\LocalCut.

Launch

Double-click localcut.exe, or start it from a terminal and open a file directly:

.\localcut.exe interview.mp4

Import media

Drag files into the media bin or press Ctrl+I. Supported: MP4, MKV, MOV, WAV and PNG.

Make your first cuts

  1. Drag a clip onto the video track.
  2. Click the ruler to place the playhead.
  3. Press S to split, select the part you do not want, press Delete.

Export locally

Press Ctrl+E, choose a preset and a destination, and start the export. The file is written to disk on your machine.
