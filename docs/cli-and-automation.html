CLI and configuration

Command-line flags, batch jobs, project files and config paths.

Usage

The same executable works as a command-line tool. Commands run without opening the window.

localcut <command> [options]
localcut --help

Commands

exportRender a project to a media file.
probePrint codec, duration and frame rate of a file.
versionPrint the version number.

Export flags

--presetExport preset name, such as web-h264
--codech264 or h265
--hwauto (default), nvenc, qsv, amf, cpu
--outOutput file path
localcut export talk.lcut --preset archive-h265 --hw nvenc --out talk.mkv

Batch operations

Get-ChildItem *.lcut | ForEach-Object {
  localcut export $_.FullName --preset web-h264 --out "$($_.BaseName).mp4"
}

Project files

A project is a single .lcut file. It stores the timeline and references media by path, so keep source files where they are or relink them on open.

Config directory

Settings%APPDATA%\LocalCut\settings.json
Cache%APPDATA%\LocalCut\cache
Logs%APPDATA%\LocalCut\logs
explorer %APPDATA%\LocalCut

Exit codes

0Success
1Read or export error
2Invalid arguments
