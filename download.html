Verify the download

Compute the SHA-256 hash and compare it with the value in SHA256SUMS.txt published with the release.

certutil -hashfile LocalCut-0.2.12-win64.zip SHA256
Get-FileHash .\LocalCut-0.2.12-win64.zip -Algorithm SHA256

System requirements

OSWindows 10 (1809+) or Windows 11, 64-bit
Memory8 GB RAM recommended
GPUDirectX 11 capable; NVENC, Quick Sync or AMF for hardware encoding
FFmpegRuntime libraries are bundled in the zip. Nothing to install.

Install

  1. Download the zip and verify the hash.
  2. Right-click, choose Extract All, and pick a folder such as C:\Tools\LocalCut.
  3. Run localcut.exe.
