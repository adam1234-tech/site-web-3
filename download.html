Verify your download

Compare the hash of the file with the value in SHA256SUMS.txt from the release page.

certutil -hashfile AdamApp-0.2.12-x64.exe SHA256

Or in PowerShell:

Get-FileHash .\AdamApp-0.2.12-x64.exe -Algorithm SHA256

Install

  1. Download the .exe and verify the checksum.
  2. Move it to a folder you own, such as C:\Tools\AdamApp.
  3. Double-click to run. If SmartScreen appears, choose More info, then Run anyway.
