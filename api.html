CLI and automation

Run exports and batch jobs from the command line or a script.

Overview

The same executable works as a command-line tool. Run adamapp with a command and its options. Commands run without opening the window.

adamapp <command> [options]

Commands

exportRender a project to a media file.
probePrint codec, duration and frame rate of a file.
versionPrint the version number.

export options

--codech264 or h265
--outOutput file path
--hwauto (default), nvenc, qsv, amf or cpu
adamapp export talk.adam --codec h265 --hw nvenc --out talk.mp4

Batch export

Use a PowerShell loop to export every project in a folder:

Get-ChildItem *.adam | ForEach-Object {
  adamapp export $_.FullName --out "$($_.BaseName).mp4"
}

Exit codes

0Success
1Export or read error
2Invalid arguments
